# Hello, I'm Pablo Villoslada-Blanco 👋

## 🌟 About Me
Postdoctoral Researcher at CNIO working on AI-driven multiomics integration for early detection of Pancreatic Ductal Adenocarcinoma (PDAC).

My work focuses on:
- Robust modeling under high-dimensional (p >> n) settings
- Multimodal data integration with missing modalities
- Translating complex omics signals into clinically meaningful predictions

Currently leading data integration and modeling efforts in the PANCAID Horizon Europe project (>1500 patients, multi-center cohort).

## 💻 Core Expertise
- Multiomics integration (early, intermediate, late fusion)
- Machine Learning and Deep Learning under missing data and modality dropout
- High-dimensional statistical modeling (p >> n)
- Clinical prediction modeling and validation
- Microbiome and virome analysis pipelines

## 🌐 Featured Projects

### PANCAID

AI-based early detection of pancreatic cancer using liquid biopsy multiomics data.

- Designed data harmonization and integration strategies across >15 centers
- Developed multimodal Machine Learning pipelines robust to missing modalities
- Implemented rigorous training/validation schemes to prevent overfitting in p >> n settings
- Focus on clinical translation and validation

### PDACMOC
Consensus molecular classifier for PDAC.

- Designed a consensus classification framework for reliable, robust, and reproducible subtype assignment
- First-author publication in Q1 journal
- Developed and maintained an R package and Shiny app for reproducible use

🔗 Paper: https://link.springer.com/article/10.1186/s13073-025-01568-9

🔗 R package: https://github.com/pavillos/PDACMOC

🔗 Shiny app: https://pdacmoc.cnio.es/
